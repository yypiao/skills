# 商品视频 Seedance 输出模板

脚本会输出两份文件：

1. `*-prompt.txt`：只给 Seedance 的简版总提示词；
2. `*.md`：简版提示词 + 详情证据，方便人工复核。

## 简版提示词结构

```text
【全局】
比例、总时长、视频类型、风格、人物一致性、场景、镜头、光线、商品图绑定、声音策略。

【镜头 1｜开始–结束｜销售任务】
比例/景别/销售任务。
场景和人物关系。
画面动作。
商品阶段。
镜头。
光线色彩。
参考帧绝对路径。
屏幕文字/UI。
声音处理。
段尾切换。

【镜头 N】
...

【声音后期】
后期配音/BGM/音效策略。
```

## 复刻风格卡（8 块）

`result.json` 顶层新增 `creativeProfile`，在 Shots 之外汇总整条片的统一基调，字段顺序固定：

1. `style`：写实/UGC/棚拍等整体质感；
2. `environment`：室内外、固定场景、背景陈设的保守描述；
3. `tonePacing`：语气、语速、切点密度、开场钩子；
4. `camera`：自拍/他拍、景别、特写占比、手持感；
5. `lighting`：亮度、饱和度、对比度与全片一致性（PIL 数值支撑）；
6. `character`：是否有人、同一人/手部/无人；年龄、族裔、配饰、人数不做武断结论；
7. `backgroundSound`：是否有口播、语速；BGM 风格在缺少音频能量分析时只标“以原片为准”；
8. `transitionEditing`：硬切数量、平均/最短镜头时长、字幕密度。

每块包含 `summary`、`tags`、`confidence`（high/medium/low/user）和 `evidence`。本地视觉模型不可靠的细项必须标记为“以参考帧/用户补充为准”，不能编造。`observations.global` 可用同名键（如 `style`、`environment`、`cast`、`backgroundSound`、`transitionEditing`）人工覆盖，覆盖后 `confidence=user`。简版提示词在 Shots 后、声音后期前追加这 8 块。

## 详情证据结构

- 成片信息；
- Story 一句话；
- 简版总提示词；
- 分段提示词；
- 参考帧绑定清单；
- 每镜 OCR、Vision 粗标签和声音证据；
- 原片声音稿；
- 品牌、价格、规格、功效占位替换稿；
- 反向约束；
- 建议补充素材。

## 关键规则

- 原品牌、原包装 logo、原价格只在证据区出现；
- 简版提示词不直接复制原品牌和未经确认的商业信息；
- 商品表面字样与叠加字幕分开处理；
- 每镜必须绑定参考原帧，商品镜头还必须绑定用户商品图；
- 无人视频不新增人物；无口播视频不新增旁白；
- 用户未确认的参数、价格、折扣、配件和功效一律占位或删除。
